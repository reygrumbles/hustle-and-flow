# Hustle & Flow v0.3

Mobile-first freestyle rhyme trainer.

## v0.3 changes
- Compact dropdown setup: Mode / Time / Rhymes
- Both remains the default rhyme mode
- Cypher timer choices: 30 / 60 / 90 seconds
- Dual Cypher mode with Lane B entering exactly 15 seconds after Lane A
- Current word/header compressed so the rhyme bank is the visual hero
- Focus mode hides setup UI and attempts browser fullscreen
- Focus controls stay behind a small three-dot handle
- Dual Focus mode shows two independently scrollable stacked rhyme banks
- Up to 1,000 perfect and 1,000 near rhyme results requested per seed word

No database or user account required.
